# RyzeMCBE Allay v0.14.2

Esta actualización incluye cambios del núcleo desde [v0.14.1](https://github.com/RyzeMCBE/Allay/releases/tag/v0.14.1).

## Minecraft Bedrock multiversión

- Última familia integrada: **Minecraft Bedrock 1.26.50–1.26.52 (protocolo 2193)**.
- Protocolos internacionales específicos registrados desde **1.21.90 (818)** hasta **1.26.52 (2193)**; también hay variantes NetEase.
- No se afirma compatibilidad con todas las versiones intermedias ni con todos los mundos y plugins sin pruebas dentro del juego.

## Mundos y dimensiones

- Modo `SHARED` para almacenamiento LevelDB conjunto y modo `SEPARATE` para Overworld, Nether y The End en carpetas independientes.
- Rutas configurables, comprobaciones previas de almacenamiento, importación de ciertos mapas Bedrock/PocketMine y recuperación de conversiones interrumpidas.
- Correcciones de paletas, subchunks y lecturas de mundos heredados.

## Portales y protección

- Sincronización de cambios de dimensión y envío de chunks correspondientes al destino, con corrección de reentrada en portales Nether.
- Soporte de apariciones seguras para mapas personalizados del End sin destruir construcciones existentes.
- API `EntityPortalEnterEvent#setDestinationOverride(Location3d)` para destinos específicos por plugins.
- **Inmunidad temporal durante las pantallas de carga**: mientras está activa se evita recibir daño y atacar. Se libera tras movimiento validado posterior a `END_LOADING_SCREEN`, con límites para impedir inmunidad indefinida.

## Mantenimiento

- Eliminación de registros temporales de desarrollo y diagnóstico de carga/dimensiones y rotura de bloques. Los errores reales siguen registrándose.
- README y guía de releases actualizados.

El cambio nuevo de Protocol contiene **solo pruebas de regresión del formato de red 2193**. No incorpora serializadores experimentales que provocaron desconexiones `Block`.

## Instalación

Requiere **Java 21**. Descarga los archivos adjuntos `Allay-0.14.2.jar` y `Allay-0.14.2.jar.sha256` cuando este release se publique y comprueba su integridad:

```bash
sha256sum -c Allay-0.14.2.jar.sha256
java -jar Allay-0.14.2.jar
```

**Antes de actualizar:** realiza una copia de seguridad completa de mundos, configuraciones y datos. Valida las transferencias Overworld ↔ Nether ↔ End, el acceso de clientes y la carga de mapas personalizados antes del despliegue en producción.
